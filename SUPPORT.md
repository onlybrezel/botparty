# Support

## Questions and setup problems

Search the documentation and existing GitHub issues first. If the problem is still open, create an issue with:

- the BotParty version or commit;
- operating system and deployment method;
- relevant configuration with secrets removed;
- logs and exact reproduction steps.

Community support is provided on a best-effort basis. Self-hosted installations do not include an uptime or response-time guarantee.

## Bugs and feature requests

Use the GitHub issue templates for reproducible bugs and concrete feature proposals. Keep unrelated requests in separate issues.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).
