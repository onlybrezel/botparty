# Security Policy

## Supported Versions

BotParty currently receives security fixes on the latest `main` branch and the latest tagged release.

## Reporting a Vulnerability

Please do **not** open public GitHub issues for security reports.

Use one of these channels instead:

1. GitHub private vulnerability reporting for `onlybrezel/botparty`
2. Email: `security@botparty.live`

Include:

- a short description of the issue
- affected version / commit
- reproduction steps or proof of concept
- impact assessment
- any suggested mitigation if you have one

If you are reporting against your own self-hosted fork, replace the contact address above with your operator mailbox before going live.

## Response Expectations

- initial acknowledgement within 3 business days
- status update after triage
- coordinated disclosure after a fix is available

## Safe Harbor

Please act in good faith, avoid privacy violations or destructive testing, and only access data that belongs to your own test accounts or systems you are authorized to assess.
